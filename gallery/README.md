# Gallery

Every image in this folder shows up in the **Gallery** section of the site.
Drop a file in and it appears — nothing else to edit.

Works with `.jpg`, `.jpeg`, `.png`, `.webp`, `.gif`, `.svg`, and `.avif`.

## Naming

The filename becomes the caption under the drawing, so name files the way you
want them read:

    peony-study.jpg            ->  "Peony study"
    2026-05-hands-practice.png ->  "Hands practice"

A `YYYY-MM` or `YYYY-MM-DD` prefix is stripped from the caption, so you can use
it to keep the folder in order.

## Size

Photos straight off a phone are often 4–8 MB, which makes the page slow to load.
Around 1500px on the long edge is plenty for a website. On an iPad you can open
the image in Photos, tap the crop tool, and export a smaller copy — or just mail
it to yourself at "Medium" size and save that.

## From an iPad

On github.com, open this folder, tap **Add file → Upload files**, pick your
images, and tap **Commit changes**. They show up on the site a minute later.
